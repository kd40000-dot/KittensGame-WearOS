# Kittens Village Watch Face

A resource-only Watch Face Format v2 watch face for Wear OS 5+.

- 8 complication slots (the WFF maximum)
- defaults each slot to the Kittens Wear `Kittens resource` provider when installed
- supports SHORT_TEXT and RANGED_VALUE
- Kittens Dark and Dracula palettes
- central digital time
- round-screen-first 450×450 logical canvas

Because the Kittens provider stores the chosen game resource per complication instance,
configure each slot once in the watch-face editor to choose Catnip, Wood, Minerals, etc.
